# YunoUilib

Patched UE-LIB used by the Rivals script.

Changes vs stock UE-LIB:
- Main window tabs centered
- Inner tabboxes wrap to two rows when there are 5+ tabs (no overlapping names)
- Sliders stay thin and fill by percent, not a 232px block
- Toggle keybinds sit next to the label
- Bottom-right resize blob hidden
